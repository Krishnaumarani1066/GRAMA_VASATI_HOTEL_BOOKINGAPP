# Grama Vasati Hotel Booking App

> An Android application providing a user-friendly interface for discovering and booking hotels — crafted by **Krishna Lagamappa Umarani**.

## Features

- **Browse Hotels** — Explore a curated list of hotels with detailed information and imagery.
- **Search** — Find hotels based on location, dates, and personal preferences.
- **User Profile** — Manage your profile, bookings, and preferences in one place.
- **Reviews and Ratings** — Read authentic reviews for hotels you've stayed at.

---

## Getting Started

### Prerequisites

- Android SDK (minimum API level 26)
- Android Studio (latest stable recommended)

### Installation

1. Clone this repository to your local machine:

```bash
git clone https://github.com/Krishnaumarani1066/GRAMA_VASATI_HOTEL_BOOKINGAPP.git
```

2. Open the project in Android Studio.

3. Build and run the app on an emulator or physical device.
